### Bundle Analysis Tools for React Native (with Metro Bundler)

This document summarizes the experience and findings when attempting to use various bundle analysis tools with a React Native project (RN 0.80.1, Metro 0.82.5) to verify code splitting and inspect bundle contents.

---

#### 1. `react-native-bundle-visualizer`

*   **Purpose:** To visualize the size and content of React Native JavaScript bundles, often showing a treemap breakdown of modules.
*   **Usage Command(s) Attempted:**
    ```bash
    # Generate bundle and sourcemap
    npx react-native bundle --platform android --dev false --entry-file index.js --bundle-output android/app/src/main/assets/index.android.bundle --assets-dest android/app/src/main/res --sourcemap-output android/app/src/main/assets/index.android.bundle.map

    # Run visualizer
    npx react-native-bundle-visualizer --bundle-path android/app/src/main/assets/index.android.bundle --sourcemap-path android/app/src/main/assets/index.android.bundle.map
    ```
*   **Problem(s) Encountered:**
    *   **"InvalidMappingColumn" Error:** The tool consistently failed with a source map error, indicating a mismatch between the generated code and the source map. Example: "Your source map refers to generated column Infinity on line X, but the source only contains Y column(s) on that line."
    *   **Incorrect Platform Assumption:** Despite specifying Android paths, the tool's internal logs showed it attempting to generate and analyze an `ios.bundle` in a temporary directory.
    *   **Unexpected Re-bundling:** The tool appeared to attempt re-bundling the application rather than just analyzing the provided bundle.
*   **Solution/Outcome:** The tool proved incompatible and unreliable for this project's setup, failing to provide any useful visualization.

---

#### 2. `source-map-explorer`

*   **Purpose:** A generic JavaScript bundle analyzer that creates an interactive treemap visualization of bundle contents using source maps.
*   **Usage Command(s) Attempted:**
    ```bash
    # Install (as dev dependency)
    npm install --save-dev source-map-explorer

    # Run explorer
    npx source-map-explorer android/app/src/main/assets/index.android.bundle android/app/src/main/assets/index.android.bundle.map
    ```
*   **Problem(s) Encountered:**
    *   **"InvalidMappingColumn" Error:** Similar to `react-native-bundle-visualizer`, this tool also failed with source map errors, indicating incompatibility with Metro's generated source maps.
    *   **`ENOENT` (No Such File or Directory):** Initially failed because the bundle file was not present, despite `npx react-native bundle` reporting success. This was resolved by ensuring the directory existed and re-running the bundle command.
*   **Solution/Outcome:** Despite successfully generating the bundle and sourcemap files, `source-map-explorer` could not parse Metro's source maps, rendering it unusable for analysis in this context.

----- 

#### 3. `react-native-bundle-discovery` (from `retyui/react-native-bundle-discovery`)

*   **Purpose:** To visualize and analyze the bundle size of React Native apps, explore codebase, and identify large packages (as per its GitHub README).
*   **Usage Command(s) Attempted:**
    ```bash
    # Install (as dev dependency)
    npm install --save-dev react-native-bundle-discovery

    # Modify metro.config.js (as per tool's instructions)
    # ... (added custom serializer to metro.config.js)

    # Build application to generate metro-stats.json
    npm run android-release

    # Run server to view report
    npx react-native-bundle-discovery server metro-stats.json
    ```
*   **Problem(s) Encountered:**
    *   **`TypeError: Cannot read properties of undefined (reading 'replace')`:** The web interface failed to load the report, indicating an incompatibility with the `metro-stats.json` format generated by Metro 0.82.5. The tool's internal data preparation logic encountered an `undefined` value where it expected a string with a `.replace()` method.
*   **Solution/Outcome:** The tool failed to process the `metro-stats.json` output, making it unusable for bundle analysis in this project.

---

#### Overall Conclusion on Bundle Analysis Tools with Metro (RN 0.80.1, Metro 0.82.5)

All three bundle analysis tools attempted (`react-native-bundle-visualizer`, `source-map-explorer`, `react-native-bundle-discovery`) encountered significant compatibility issues with the output generated by Metro Bundler in this React Native project. These issues ranged from problematic source maps to incompatible `metro-stats.json` formats.

This indicates that relying on generic or community-maintained bundle analysis tools for this specific React Native/Metro version combination is challenging. Manual inspection of the APK contents (renaming to `.zip` and checking the `assets` folder) remains the most reliable method for confirming bundling behavior, which in this case, showed that code splitting for `React.lazy` is not occurring in release builds by default.
