## Setup the Projects

1. Clone Repo

   `git clone http://repo-almtools/scm/react/reactnativewave.git`

2. Checkout dev

   `cd reactnativewave`

   `git checkout dev`

3. Node Module Installation

   `npm install -f`

4. Running Project

   1. Open Emulator and Verify Emulator

      `adb devices`

   2. Run the Project

      `npm run android`

   3. Node Server Not Started

      `npm start`
