## Fast App Build for Development

## Run below commmands in cmd (commands mentioned in package.json )

## 1. Install app from path

`npm run adb-install`

## 2. open app

`npm run adb-open-app`

## 3. connect metro

`npm run adb-connect`

## 4. run npm start and press r (for reload app)

`npm start`

## Delete node_modules faster

### Install the package globally

`npm install -g remove-node-modules`

or

`npm install -g rimraf`

### Make sure you're in the RN project folder and execute the below command

`remove-node-modules`

or

`rimraf node_modules`

## list scripts in cmd

`npm install -g ntl`

`ntl` -> Will display list of tasks/scripts in package.json file
